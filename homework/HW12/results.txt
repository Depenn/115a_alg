1. DFA examples
======================================================================
a*  (1 states)
  ''           -> True   path q0
  'aaa'        -> True   path q0 q0 q0 q0
  'aab'        -> False  path q0 q0 q0 None

a* b+  (2 states)
  'a'          -> False  path A A
  'aab'        -> True   path A A A B
  'aabaa'      -> False  path A A A B None
  'abbb'       -> True   path A A B B B

even number of 0s  (2 states)
  '010'        -> True   path E O O E
  '101'        -> False  path E E O O
  '10100'      -> False  path E E O O E O
  '1010010'    -> True   path E E O O E O O E

binary divisible by 3  (3 states)
  '0'          -> True   path 0 0
  '11'         -> True   path 0 1 0
  '110'        -> True   path 0 1 0 0
  '1001'       -> True   path 0 1 2 1 0
  '1010'       -> False  path 0 1 2 2 1

  check: every n < 1000 -> True

2. NFA with epsilon moves, subset construction
======================================================================
contains 'aba' (NFA)  (5 states)
  'ab'         -> False
  'aaba'       -> True
  'bbabab'     -> True
  'abba'       -> False

  subset construction -> DFA with 6 states, minimized -> 4 states

  k-th symbol from the end is 1:
   k | NFA states | DFA states (subset) | minimal DFA
   1 |          2 |                   2 |           2
   2 |          3 |                   4 |           4
   3 |          4 |                   8 |           8
   4 |          5 |                  16 |          16
   5 |          6 |                  32 |          32
   6 |          7 |                  64 |          64
   7 |          8 |                 128 |         128
   8 |          9 |                 256 |         256
   9 |         10 |                 512 |         512
  10 |         11 |                1024 |        1024
  -> the DFA needs 2^k states: the NFA is exponentially smaller.

======================================================================
3. DFA minimization (Moore partition refinement)
======================================================================
  'even number of a' built with 4 states -> minimal DFA has 2 states
  minimal transitions: [((0, 'a'), 1), ((0, 'b'), 0), ((1, 'a'), 0), ((1, 'b'), 1)], finals {0}
  divisible by 2: 2 states -> minimal 2
  divisible by 3: 3 states -> minimal 3
  divisible by 5: 5 states -> minimal 5
  divisible by 6: 6 states -> minimal 4
  divisible by 8: 8 states -> minimal 4

======================================================================
4. a^n b^n is not regular: a pigeonhole counterexample for every DFA
======================================================================
  DFA correct up to n=1 (4 states): a^2 and a^3 reach the same state -> wrong on 'aabb' (says False, truth True)
  DFA correct up to n=3 (8 states): a^4 and a^5 reach the same state -> wrong on 'aaaabbbb' (says False, truth True)
  DFA correct up to n=5 (12 states): a^6 and a^7 reach the same state -> wrong on 'aaaaaabbbbbb' (says False, truth True)
  DFA correct up to n=8 (18 states): a^9 and a^10 reach the same state -> wrong on 'aaaaaaaaabbbbbbbbb' (says False, truth True)
  More states only move the error further out; it never disappears.

1. Decider for a^n b^n c^n (not context-free)
======================================================================
  ''           -> accept    1 steps   final tape 
  'abc'        -> accept    8 steps   final tape XYZ
  'aabbcc'     -> accept   23 steps   final tape XXYYZZ
  'aabbc'      -> reject   13 steps   final tape XXYYZ
  'abcabc'     -> reject    7 steps   final tape XYZabc
  'acb'        -> reject    1 steps   final tape Xcb
  'aaabbbccc'  -> accept   46 steps   final tape XXXYYYZZZ

  step-by-step on 'abc' (state, tape with [head]):
    q0   [a]bc
    q1   X[b]c
    q2   XY[c]
    q3   X[Y]Z
    q3   [X]YZ
    q0   X[Y]Z
    q4   XY[Z]
    q4   XYZ[_]
    acc  XYZ[_]

  steps grow like n^2 (the head sweeps back and forth once per round):
     n | steps | steps / n^2
     1 |     8 | 8.00
     2 |    23 | 5.75
     4 |    77 | 4.81
     8 |   281 | 4.39
